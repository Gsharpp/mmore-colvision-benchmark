# mmore-colvision-benchmark

Benchmark suite comparing ColVision models (ColPali, ColQwen2, ColQwen2.5, ColQwen3, ColGemma3) within the [mmore](https://github.com/swiss-ai/mmore) RAG pipeline (PR #305).

## Scope

- **Track A** — main benchmark on English medical PDFs with figures, including a corpus scaling study (100 → 50k pages).
- **Track B** — multilingual benchmark across 6 languages (EN, FR, DE, ES, ZH, AR), focused on cross-script retrieval performance.
